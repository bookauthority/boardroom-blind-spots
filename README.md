# Boardroom Blind Spots: Executive Strategies for Preventing AI Model Collapse in Financial Services

**Companion code and practical exercises for _Boardroom Blind Spots: Executive Strategies for Preventing AI Model Collapse in Financial Services_.**

**Book author:** Kaelen Vane

## About the book

This book provides a comprehensive framework for financial services executives and board members to identify, assess, and mitigate systemic risks arising from autonomous AI model failures. It translates complex technical and regulatory challenges into actionable governance strategies, equipping leadership with practical tools for oversight, scenario analysis, and crisis management. The content emphasizes the importance of executive engagement, regulatory compliance, and cross-functional collaboration to prevent and respond to AI-driven systemic threats within financial institutions.

## Who this is for

Financial services executives and board members responsible for oversight of AI-driven systems

This repository accompanies the book with chapter-specific implementation projects, examples, and reproducible exercises. Each implementation folder has its own README with the setup and execution instructions relevant to that chapter.

## Getting started

1. Read the chapter you want to explore in the book.
2. Open the corresponding `chapter-XX/` folder above, where an implementation is available.
3. Follow that folder’s `README.md` for prerequisites, setup, configuration, and commands.
4. Run the chapter’s examples and compare the results with the discussion in the book.

Different chapters may have different dependencies and environment requirements; use the instructions in each chapter folder rather than assuming one setup works for all projects.
